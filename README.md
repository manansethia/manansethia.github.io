## 🛠️ Technological Architecture

We rejected bulky frameworks in favor of a strictly optimized, handcrafted pipeline.

<div align="center">
  <img src="https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white" />
  <img src="https://img.shields.io/badge/Sass_/_CSS3-CC6699?style=for-the-badge&logo=sass&logoColor=white" />
  <img src="https://img.shields.io/badge/JavaScript-323330?style=for-the-badge&logo=javascript&logoColor=F7DF1E" />
  <img src="https://img.shields.io/badge/Jekyll-CC342D?style=for-the-badge&logo=jekyll&logoColor=white" />
  <img src="https://img.shields.io/badge/Ruby-CC342D?style=for-the-badge&logo=ruby&logoColor=white" />
  <img src="https://img.shields.io/badge/Markdown-000000?style=for-the-badge&logo=markdown&logoColor=white" />
  <img src="https://img.shields.io/badge/Cloudflare_Edge-F38020?style=for-the-badge&logo=cloudflare&logoColor=white" />
  <img src="https://img.shields.io/badge/GitHub_Actions-2088FF?style=for-the-badge&logo=github-actions&logoColor=white" />
</div>

- **The Engine:** Powered by **Jekyll** (Ruby), customized directly from the *Minimal Mistakes/Academic Pages* boilerplate wrapper, completely modernized.
- **The Design:** Modified SCSS featuring **CSS Grid**, glassmorphism, fluid micro-animations, and system-native **SF Pro** fonts.
- **The Delivery:** Pure `AVIF` High-Fidelity imagery, custom fallback logic, strict HTTP/3 Edge caching via Cloudflare, and over **20MB** of iframe data blocked in favor of lightweight JS facades.

## 📂 Repository Anatomy

A quick-glance tree for visiting developers:

```text
📦 manansethia.github.io
 ┣ 📂 _data         # Data sets for UI logic (e.g., UI Text)
 ┣ 📂 _includes     # Core HTML fragments (Headers, Footers, Navbars)
 ┣ 📂 _layouts      # Structural page wrappers
 ┣ 📂 _pages        # Primary route components (Resume, Projects, Blogs)
 ┣ 📂 _sass         # Segmented Sass architectures
 ┣ 📂 assets        # Root CSS and minified JS bundles
 ┣ 📂 images        # High-Fidelity 4k Retina Media (.avif)
 ┣ 📜 _config.yml   # App configuration & Jekyll Plugin mapping
 ┗ 📜 _headers      # Cloudflare Early Hints & Native CSP Headers
```
