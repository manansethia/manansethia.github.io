🌙 Night Mode & Hibernation

Systemd timers · Saves ~800MB–1.5GB RAM nightly

🕙 23:00 — Sleep Script

Systemd timer stops Nextcloud PHP-FPM, both NC PostgreSQL and Redis, Conduit, Element Web, Dashdot. Immich, AdGuard, Tailscale, Gotify remain running.

# /etc/systemd/system/sleep-mode.timer [Timer] OnCalendar=23:00 Persistent=true # /etc/systemd/system/sleep-mode.service [Service] ExecStart=/usr/local/bin/sleep-mode.sh # sleep-mode.sh systemctl stop nextcloud-php-fpm systemctl stop nextcloud-postgres systemctl stop nextcloud-redis systemctl stop conduit dashdot

🌅 07:00 — Wake Script

Systemd timer restarts all services in dependency order. PostgreSQL starts first (30s delay), then Redis, then PHP-FPM. Avoids RAM spike from simultaneous starts.

# wake-mode.sh systemctl start nextcloud-postgres sleep 30 systemctl start nextcloud-redis sleep 10 systemctl start nextcloud-php-fpm sleep 10 systemctl start conduit dashdot

🧠 02:00 — ML Night Indexing

Nightly job: activate OC, run Immich ML jobs (face detect, CLIP embeddings, new photo thumbnails), disable OC. Only incremental — new uploads since last run. No full re-index after prelim.

# ml-night.sh (runs at 02:00) echo 2800000 | tee \ /sys/devices/system/cpu/cpu*/cpufreq/scaling_max_freq # Trigger Immich jobs via API curl -X POST http://localhost:2283/api/jobs/run \ -H "x-api-key: $IMMICH_KEY" \ -d '{"jobName":"thumbnailGeneration"}' # ... face, clip etc sleep 3600 # allow 1hr echo 2400000 | tee \ /sys/devices/system/cpu/cpu*/cpufreq/scaling_max_freq

💤 HDD Spin-Down

Backup HDD sleeps most of the day — only spins up for nightly rsync (03:00). Main 1TB HDD spins down after 10min of no photo access. Saves ~2W continuously during idle periods.

# /etc/hdparm.conf /dev/sda { # 1TB main spindown_time = 120 # 10 min } /dev/sdb { # 500GB backup spindown_time = 60 # 5 min } # Verify spin state hdparm -C /dev/sda

📋 Legend & Key Decisions

Airtel GPON

Locked ISP gateway. Cannot replace, cannot modify DNS/DHCP. Handles optical fibre termination only.

Archer A5

Your controlled layer. DHCP hands Pi 5's IP as DNS to every connected device automatically.

Pi 5 Core

All heavy services. Carefully tuned for 4GB. ZRAM essential. CPU-only ML. No GPU accel.

Uno Q Utility

Survives Pi 5 reboots. Passwords, monitoring, dashboard always up independently.

Tailscale

WireGuard. Punches double NAT. Zero open ports. AdGuard filters all devices globally.

SSD (system)

Fast random I/O for databases, cache, thumbnails, OS. SSD speed critical for DB performance.

1TB HDD (main)

Bulk photo/video storage. Spins down after 10min idle. 2.0W idle. 0.1W sleep.

500GB HDD (backup)

Nightly rsync backup. Sleeps ~22hrs/day. Saves ~2W vs always-on. PCIe USB HAT.

ZRAM (both)

Pi 5: 1.6GB compressed. Uno Q: 820MB. zstd algorithm. Active even at idle on Pi 5.

Night Mode

Systemd timers stop NC+Conduit at 23:00. Wake at 07:00. ML jobs at 02:00 with OC.

Prelim Stage

First-run only. Only Immich, OC 2.8GHz, buffalo_L model, maximum performance indexing.

Double NAT

Airtel + Archer = double NAT. Fine for home use. Tailscale WireGuard punches through effortlessly.
